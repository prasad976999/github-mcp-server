An MCP server that gives Claude safe, structured access to GitHub

Built step by step with the official MCP Python SDK. This guide covers the plan, every step, the code line by line, the tests, and the questions you'll be asked about it.

How the pieces fit

Host: Claude Desktop, Claude Code or the MCP Inspector

The app the user talks to. It starts the server (stdio) or connects to it over HTTP, and calls its tools.

JSON-RPC over stdio, or HTTP with a bearer token (Docker)

github-mcp server (this project)

server.pyMCP layer: 9 tools, 1 resource, 2 prompts, validation, errors for the model
github_client.pyHTTP layer: auth, retries with backoff, rate limits, pagination
models.pyWhat the model sees: trimmed, typed outputs
config.pySettings and secrets from the environment
http_app.pyHTTP mode: bearer token, Host check, /health
HTTPS with a read-only token

GitHub REST API

api.github.com: repositories, contents, issues, pull requests, rate limit.
